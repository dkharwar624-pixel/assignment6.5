In this mini-project I built a complete profile card and a product card component using all the CSS concepts learned so far. For the profile card, I included a profile image, name as Aman Sharma, role as Frontend Developer, a short description about my experience, a list of skills like HTML, CSS, JavaScript, React and Box Model, and a contact button at the bottom. I used box model properties effectively by setting width 320px and max-width 90% for responsiveness, padding of 30px for inner spacing, margin of 20px for outer spacing, and border of 2px solid light gray. I added background as a subtle white gradient, border and border-radius of 20px to make it look modern with rounded corners, and box-shadow for elevation. I placed a PRO badge using positioning by making the parent card position relative and the badge position absolute with top 15px and right 15px and z-index 10. Similarly, for the product card I included a product image, product name as Nike Air Max Sneakers, price with old and new price, short description about comfort and features, and a Buy Now button. I used width 300px, overflow hidden to keep the image inside border-radius, background white, border 2px, and border-radius 16px. A 50% OFF badge was placed using absolute positioning on the top-left corner of the card. Both cards have meaningful class names like profile-card, profile-image, skill-tag, product-badge, etc., and I tested them on different screen widths using flex-wrap and media queries for max-width 600px where cards become full width on mobile, making them fully responsive.For Screenshot: Open the page on laptop and mobile (use Chrome DevTools responsive mode) and take screenshot showing both cards side-by-side with badges visible.
